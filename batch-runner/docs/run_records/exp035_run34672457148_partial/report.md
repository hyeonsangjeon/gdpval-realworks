## 왜 `results/`가 아니라 여기에 있나

`batch-runner/results/` 아래는 **대시보드에 발행되는 실험** 자리입니다.
중단된 실행을 거기 두면 발행에 필요한 `report_data.json`이 없어 빌드가 서고,
폴더 이름을 바꿔도 `short_id`가 충돌합니다. 끝나지 않은 실행의 보존 기록은
`docs/run_records/` 아래에 둡니다.
